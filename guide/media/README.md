# Картинки учебника

Все файлы уже подключены в `qidi_q2_handbook_2026_v2.html`.  
Источники и ограничение «только домашний офлайн»: [`SOURCES.txt`](SOURCES.txt).

Подпапки:

- `box_pages/` — сырые страницы PDF Start Guide (можно не открывать)
- `box_pdf/` — вырезанные объекты из PDF (не используются в HTML)

Основные файлы лежат в корне `media/` и открываются из HTML относительными путями `media/...`.
